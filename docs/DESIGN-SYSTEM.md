# Design System & Variations - Moonshine Capital Broker Commission Calculator

## Overview
This application incorporates four distinct design systems reflecting different visual aesthetics while sharing a single authoritative financial calculation engine.

## 1. Variant 1 — Punk Utility Brutalism (Production Default)
- **Theme ID**: `punk-utility-brutalism`
- **Aesthetic**: Hard-edged financial utility, independent-business operating platform.
- **Color Tokens**: Near Black (`#080808`), Panel Black (`#141414`), Electric Green (`#00F23D`), Off-White (`#F7F7F4`), Muted Gray (`#929292`), Rule Gray (`#292929`).
- **Typography**: Heavy condensed grotesque headings (Barlow Condensed style), Inter body, IBM Plex Mono metadata.

## 2. Variant 2 — Broker's Manifesto
- **Theme ID**: `brokers-manifesto`
- **Aesthetic**: Independent-finance editorial experience, neo-brutalist publishing, collage art, technical diagrams.
- **Color Tokens**: Warm Paper (`#F2EBDD`), Ink Black (`#151515`), Acid Lime (`#D7FF32`), Charcoal (`#262626`), Photocopy Gray (`#85817A`).

## 3. Variant 3 — Lime Precision Fintech
- **Theme ID**: `lime-precision-fintech`
- **Aesthetic**: Polished SaaS financial platform with dark graphite hero and bright financial dashboard.
- **Color Tokens**: Near Black (`#090B09`), Deep Graphite (`#171A17`), Signal Lime (`#A7FA3B`), Lime Wash (`#E8F9D5`), Dashboard White (`#F6F7F5`).

## 4. Variant 4 — Pastel Intelligence
- **Theme ID**: `pastel-intelligence`
- **Aesthetic**: Approchable, optimistic AI-inspired financial planning interface with soft pastels.
- **Color Tokens**: Soft White (`#FCFBFF`), Lavender Wash (`#F1ECFC`), Lilac (`#D5BDFB`), Primary Purple (`#793FDC`), Mint (`#B9EAD9`), Butter Yellow (`#FFF0BE`).
